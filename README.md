# ZeroPrint 云打印

借助 [ZeroPrint](https://webappprint.cn) 将本地打印能力接入简道云，用简道云的自动化/自定义按钮直接驱动本地打印机。

## 功能

- **后端打印**：由表单数据触发，服务端生成文件后自动提交到指定打印机。
- **自定义按钮打印**：在表单上点按钮即可发起打印，无需人工下载再打印。
- **批量打印**：一次触发多个文件，并发提交（`Promise.allSettled`），并汇总每个文件的成功/失败结果。
- **多格式支持**：PDF、Office 文档、图片等常见格式，覆盖简道云三大打印模板。
- **打印参数可控**：份数、纸张大小、单/双面、颜色模式、页面方向、分辨率。
- **结果回调**：同时提供「任务 ID」和「回调地址」时，打印完成会回调指定 HTTP 触发地址。

## 配置

**全局配置（插件级）**

| 字段 | 说明 |
| --- | --- |
| 接口地址 | ZeroPrint 服务地址，默认 `https://webappprint.cn` |
| 公钥 | 从 ZeroPrint 客户端复制的 RSA 公钥 |

**触发参数（`发起打印`）**

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 打印机 ID | 是 | 从 ZeroPrint 客户端复制，64 位十六进制字符串 |
| 文件 | 是 | 附件/图片字段、智能助手「生成打印文件」节点结果，或 http(s) 链接（多个用英文逗号分隔） |
| 打印份数 | 否 | 默认 1 |
| 纸张大小 / 双面打印 / 颜色模式 / 页面方向 / 分辨率 | 否 | 从 ZeroPrint 客户端复制 |
| 任务 ID / 回调地址 | 否 | 两者同时填写才会触发打印结果回调 |

## 工作原理

1. 校验打印机 ID 与文件参数。
2. 将打印参数序列化为 JSON，使用随机 AES-256-GCM 密钥加密数据，再用 RSA-OAEP(SHA-256) 加密该密钥，整体 Base64 后 POST 到 `{接口地址}/api/print`。
3. 逐个文件提交请求（超时 10 秒），汇总失败项返回。

返回值：

- `result`：`请求成功` / `部分请求失败` / `全部请求失败`
- `detail`：失败文件地址及对应错误信息
